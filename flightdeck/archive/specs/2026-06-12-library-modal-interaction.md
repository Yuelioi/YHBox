# 子图库 modal 交互改版

## 背景

2026-06-12 编辑器 UX 收口落地后, 子图库 modal (LibraryExplorerModal) 真机一用就暴露交互问题:

- **悬停出详情手感差** — 鼠标扫过列表右栏跟着闪, 还要 250ms 去抖压 RPC。
- **单击 = 直接插入太重** — 插入是低频操作, 却占着最顺手的手势; 想看详情反而没有明确手势。
- **编辑藏在右键里没人发现** — 用户以为不支持编辑 (名称/描述/标签其实都有, 发现性为零)。
- **没有多选/批量/过滤** — 库一大整理不动。
- **"分类"是潜规则** — 拿第一个标签当分组键, 语义不清。

## 拍板决策 (2026-06-12 用户四问)

1. **分类 = 独立新字段** (不沿用"第一个标签即分类")。
2. **插入入口 = 详情面板主按钮 + 双击行**, 右键菜单里的插入保留。
3. **多选 = Ctrl/Shift+单击** (文件管理器式), 不用 checkbox。
4. **批量操作 = 批量删除 + 批量加标签** (批量移除标签不做)。

## 设计

### 1. 选中模型 (核心改动)

- **单击 = 选中** (替换式), 右栏出详情。删除悬停出详情逻辑 (`onHoverRow` + 去抖 timer 连根删)。
- **Ctrl+单击** = toggle 加选/减选; **Shift+单击** = 从锚点 (上次单击行) 到当前行范围选, 顺序按**当前过滤后的可见扁平顺序** (分组展开序)。
- **双击 = 插入引用并关 modal**。单击直接插入的旧路径删除。
- **右键** = 现有单项菜单不变 (插入引用/复制为新/编辑信息/复制 ID/删除), 右键同时把该行设为唯一选中。
- modal 重新打开时清空选中 (与现有 query 清空同处)。Esc 关 modal 行为不变。
- 选中态样式沿用现有 `bg-elevated/60` 高亮。

### 2. 右栏三态

| 选中数 | 右栏内容 |
|---|---|
| 0 | 现有空态提示 |
| 1 | 详情面板 (现状字段保留), **顶部新增「插入引用」主按钮 + 「编辑信息」按钮**; 复制为新/删除照旧 |
| ≥2 | **批量面板**: 「已选 N 个」+ 批量删除 (error 色) + 批量加标签 + 取消选择 |

批量操作放右栏 (右栏语义 = "当前选中对象"), 不另开顶部工具条。插入只对单选有效, 批量面板不提供插入。

### 3. 分类字段

- 后端 `internal/services/container/model.go` 的 `Subgraph` 加 ``Category string `json:"category,omitempty"` ``。
- **不需要新 RPC**: `SubgraphService.Update` 是整结构体 RFC7386 merge patch (无字段白名单, 已验 service_subgraph.go:91), 加字段即可改; `Duplicate` 整结构体复制, 自动带上。
- 前端 `lib/backend.ts` `Subgraph` 接口加 `category?: string`。
- **列表分组改按 category** (空 → 「未分类」), 删掉"第一个标签当分组"逻辑, 标签退回纯标记。
- 旧子图无分类 → 落「未分类」。**不写迁移代码** (内测期, 用户手动归类)。
- 编辑信息 modal 加「分类」输入: 下拉候选 = 库内现有分类去重, 支持直接输入新分类名。
- `SubgraphPropsPanel`(编辑器内子图节点属性面板) 顺手加同款分类编辑, 两处体验一致。

### 4. 过滤器 (搜索框同行/下方一行)

- **分类下拉**: 全部 / 各现有分类 / 未分类。
- **标签多选**: 选中标签后只显示**含全部所选标签**的子图 (AND)。
- 现有文本搜索保留; 三个过滤条件 AND 叠加。
- 候选列表 (分类/标签) 从 `lib.subgraphs` 现算去重, 无新后端接口。

### 5. 批量操作

- **批量删除**: 对每个选中项 `referrersOf` 扫引用 → 确认框汇总「共 N 个, 其中 M 个被容器使用: <名单>」→ 确认后逐个 `deleteSubgraph` (各自带 rev 乐观锁)。个别失败汇总成一条错误 toast, 结束后 `lib.reload()`。
- **批量加标签**: 小弹窗输入标签 (候选 = 现有标签去重, 可多个) → 对每个选中项计算「原标签 ∪ 新标签」→ `updateSilent(id, {tags: 全量数组}, rev)` 逐个提交。**RFC7386 数组是整体替换**, 必须客户端算并集后发全量。失败同样汇总一条 toast + reload。

### 6. 不做的事 (YAGNI)

- 批量移除标签 / 批量改分类 (用户没要)。
- 多选插入 N 个节点 (插入只单选)。
- 分类层级 / 分类重命名级联 (分类就是字符串, 改名 = 逐个编辑)。
- 在线 tab 不动 (占位照旧)。

## 验收

代码全绿: 类型检查 + lint + 现有测试不回归 (预存红照 cockpit 在册口径判)。

真机清单:

1. 单击条目 = 只选中出详情, **不**插入; 悬停不再改变右栏。
2. 双击条目 = 插入引用并关 modal, 缺变量自动补不回归。
3. 详情面板「插入引用」按钮插入; 「编辑信息」开编辑弹窗, 能改 名称/描述/标签/**分类**, 保存生效。
4. Ctrl+单击加选/减选, Shift+单击范围选; 选中 ≥2 右栏变批量面板。
5. 批量删除: 确认框列出被引用项「被 N 个容器使用」, 确认后全删, 列表刷新。
6. 批量加标签: 选多项加标签, 各项原标签保留新标签追加。
7. 分组按分类显示, 无分类落「未分类」; 分类下拉 + 标签多选过滤 + 文本搜索三者叠加生效。
8. 编辑器内子图节点属性面板能改分类, 与库内编辑互通。
9. 右键菜单全套仍可用; 在线 tab 占位照旧。
