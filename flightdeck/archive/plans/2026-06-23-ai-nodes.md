# AI 节点实现计划(三阶段 TDD)

> **For agentic workers:** 逐任务 TDD 落地(test → fail → impl → pass → commit)。设计权威是 [specs/2026-06-23-ai-nodes.md](../specs/2026-06-23-ai-nodes.md);本 plan 只给执行序与触点,**设计细节回 spec**,别在代码注释里写 spec 引用(违 [checklists/comments.md](../checklists/comments.md))。

**Goal:** 让图作者拖一个 AI 节点调 LLM(选连接+模型、`{{}}` 提示词 + 任意带类型动态 IO、结构化输出、vision 识图),并把 Screenshot 拆成 Capture/SaveImage/LoadImage 让 Image 成一等流动值。

**Architecture:** 复用 ① 的 `internal/services/llm.Provider`(扩 `ChatStructured`/`Images`);新 `ctx.AI()` 运行时服务做指纹缓存;新框架机制 `DynamicDataFields`(config 驱动动态 Data 字段,镜像现成 `DynamicInputs`);vision 走 exec-data 直连(`applyExecDataEdges` 扩动态输入)。

**Tech Stack:** Go 1.25.1(`yotta` module)、`openai-go/v3` v3.41.0、`anthropic-sdk-go` v1.51.1、goja 无关、Wails3 + Vue3 前端。

## Global Constraints

- **破坏性更新,不留兼容**:删 Screenshot / 改 Image 注册类型 / 扩 `Message` / 改 `applyExecDataEdges` 一次切净,无 shim、无 deprecated。
- **SDK 符号不脑补**:用任何 `openai-go`/`anthropic-sdk-go` 的 `ResponseFormat`/`Tools`/`ToolChoice`/image part 符号前,先 `go doc` 核实(① 已证两 SDK 在 1.25.1 编译);test-first 打 `httptest` 验线格式,不依赖符号记忆。
- **pin 命名**:exec-in=`In`,data pin PascalCase,Number/Integer/Duration Default 用 `json.Number("...")`;`Default` 与 `Required` 互斥(见 [checklists/add-node.md](../checklists/add-node.md) / [node-spec-style.md](../checklists/node-spec-style.md))。
- **节点类型是 UI 标签**:运行时值 = Go `float64/string/bool/map[string]any/[]any`,无 `node.Number` 中间类型。
- **验证基线**:每阶段末跑 `go build ./... && go test ./...`、`cd frontend && pnpm gen:node-i18n && pnpm typecheck && pnpm i18n:check`、`task build`;预存失败照 [checklists/build.md](../checklists/build.md) 判红(runtime fish fixture / i18n residue 42 / lint 18)。
- **commit 直推当前分支 `feat/v2-foundation`,永不 push;不跳 hook。** 每任务一 commit。
