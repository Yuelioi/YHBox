# Asset Workbench Upgrade context

## What matters

资源工作台面向普通用户，专业能力渐进披露；模板、蓝图、Macro 和 InputClip 保持各自领域语义，
共享的是浏览与管理工作流。旧视觉反馈项来自早期桌面版本，不能未经复现直接转化为当前代码任务。

## Decisions

- 1:1 是卡片和普通详情的默认保真上限，倍率变化需要真实素材库证据。
- 显示偏好只控制技术信息密度，不能成为能力权限或入口开关。
- 删除资源前必须重新检查引用，清理不能依赖陈旧列表状态。

## Terms

- **Asset Workbench:** 跨资源类型共享搜索、预览、元数据和生命周期操作的管理界面。
- **Display preference:** 纯展示密度选择，不改变可用能力。
