# 画布辅助工具栏

## Goal

把工作流画布左侧空带改造成可折叠、可配置的辅助工具栏，集中常用创作、节点快捷入口、局部编排和布局操作；
同时让右上角保留 AI 提案与自动化目标等工作流级入口，不牺牲画布空间和既有快捷键。

## Status

Open

## Current

画布左侧辅助工具栏已实现：添加节点/评论、5 个可配置常用节点、`Alt+1…5`、在 signal 连线中原子插入节点、
为两个选中节点腾位、LR/TB 布局、设置与紧凑切换。常用节点、紧凑状态和显隐状态写入本机设置；AI 提案与
自动化目标已迁到画布右上。紧凑状态保留全部图标按钮，仅隐藏分组标题和短文案；紧凑切换固定在工具栏底部，
右上与节点地图并列的开关只负责彻底显示/隐藏工具栏。工具栏整体避开画布顶部，其余内容在低高度时滚动。

相关 session/controller/keyboard/settings 测试、`task check`、`task webview:smoke` 和生产构建均通过。WebView
smoke 已更新为避开画布浮层进行框选，并验证新的左右 action ownership。当前工作区还包含上一阶段已验收但未
提交的“放弃修改并退出等待态”改动。
