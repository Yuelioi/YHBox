# 快捷入口编排优化

## Goal

让悬浮启动器在重复入口、不同显示尺寸和大量工作流下仍然清晰、可搜索、可用键盘操作，并让设置页成为真正可扩展的快捷入口编排器。

## Status

Finished

## Current

设置页实时预览及其双栏、sticky 卡片、预览定位和 `LauncherSurface` preview 专用分支已经删除，编排区恢复全宽；用户可以并排打开真实启动器观察设置实时变化。内容尺寸现为极小、小、中、大四档，全部显示布局共享同一组尺寸 token。
