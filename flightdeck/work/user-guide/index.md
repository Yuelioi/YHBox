# Yotta 用户文档

## Goal

在 Yotta 本仓库维护一套面向普通用户的中文 Markdown 文档，覆盖安装入门、工作流编辑器、节点、自动化目标、
资源与录制、启动器、运行排错等主要使用路径；内容和截图可在后续整理后发布到月离 Docs 网站。

和用户文档占据主体，开发/架构入口收敛到末尾。节点文档已按当前 Catalog 改为总分结构，拆分为流程与状态、
数据处理、自动化与输入、文件/网络/脚本/AI 四个分册；每册列常用节点、用途和注意点，并链接复杂组合场景。

端口与连线、辅助工具、默认目标、检查器、工作流设置和底部运行工作台。设置文档按当前九个设置主题建立总分说明；工作流管理、Run/调试、计划、快捷键、更新/备份也已有独立
用户页面，覆盖生效时机、配置关系、约束和错误恢复。首批中文用户指南现
包含入口、快速开始、主界面、工作流编辑器、节点参考、场景示例、自动化目标、输入录制、悬浮启动器、设置
和故障排查。五张 `4.0.0-alpha.2` 截图已
复制到指南自有 assets，并用于相应页面。现有 `docs/product/` 继续承担产品/架构说明，不与用户教程混合。
