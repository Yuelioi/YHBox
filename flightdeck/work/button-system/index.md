# 统一操作按钮体系

## Goal

为 Yotta 建立符合暗色桌面生产力工具气质的统一按钮体系，并迁移工作流、资源库、编辑器、设置中心与
分页等高频入口；主操作、普通工具、图标操作、选择态和危险操作应有稳定角色、尺寸、状态与可访问性，
不再出现亮绿色网页 CTA、描边标签和分页选中态各自为政的观感。

## Status

Finished

## Current

已完成按钮角色调研、全仓审计、共享实现和视觉验收。Nuxt UI 的 `primary + solid` 现在统一使用
accent-contained 暗色实体面、语义内描边和完整交互状态，不再使用亮绿色渐变或外投影；页面主新建、
资源库录制、编辑器运行和模态提交自动消费同一角色。

三个分页入口的当前页统一为 `primary + subtle` 选择态；编辑器资源侧栏的录制/截图、宏动作新增使用
`primary + soft` quiet accent；坐标单位与图标选择器不再复用 solid 主操作外观。普通工具继续使用
neutral soft/ghost，危险操作继续使用 error 语义。

CLI Playwright 使用真实 Edge 检查工作流、资源库和工作流编辑器，最终无 page error、无未知 RPC，
主操作文字对比度约 7.92:1；Impeccable 检测为零问题。最终 `task check` 按变更范围路由到
`check:frontend:quick`，107 个测试文件、467 个用例全部通过。

用户复验后认可整体方向，并要求 contained 主操作默认态更暗、更晶莹。共享默认 tint 已由 13% 降至
7%，hover 为 12%、active 为 5%；按钮新增薄 primary 内高光和短距离深色位移阴影，按下时阴影同步
回压。没有恢复营销式渐变、彩色发光或页面级补丁，角色矩阵和所有页面用法保持不变。

最终 CLI Playwright 对默认、hover、active 三态和代表页面复验通过；默认态文字对比度由约 7.92:1
提升到 8.79:1，页面无错误或未知 RPC。Impeccable 检测零问题，最终 `task check` 继续以退出码 0
通过 107 个测试文件、467 个用例。
