# 自动化与输入节点

自动化节点通过设置中的目标槽位操作外部程序。运行前先完成[自动化目标](../automation/index.md)配置。

## 窗口

| 常用节点 | 用途 | 注意点 |
| --- | --- | --- |
| 激活目标 | 把桌面窗口切到前台，或启动 Android 包 | 后续输入需要前台时先调用 |
| 获取窗口状态 | 读取窗口位置、尺寸或可用状态 | 可用于运行前检查 |
| 最大化 / 最小化 / 恢复窗口 | 调整窗口状态 | 状态切换完成可能需要短暂等待 |
| 移动 / 调整窗口大小 | 固定自动化空间 | 避免录制坐标与运行坐标不一致 |
| 关闭窗口 | 请求关闭目标窗口 | 未保存内容可能由目标程序自行确认 |

## 鼠标

| 常用节点 | 用途 |
| --- | --- |
| 读取指针位置 | 保存当前目标客户区比例位置 |
| 移动指针 | 移动到固定或计算位置 |
| 点击指针 | 在目标位置点击指定按钮 |
| 拖拽指针 | 从起点按住并移动到终点 |
| 滚动指针 | 发送滚动输入 |
| 按住/释放鼠标按钮 | 跨节点保持按钮状态 |

需要操作后恢复鼠标时，参考[点击后恢复位置](scenarios.md#场景二点击后恢复鼠标位置)。

## 键盘

| 常用节点 | 用途 |
| --- | --- |
| 按键 | 发送一次按下和释放 |
| 按下组合键 | 同时发送修饰键和主键 |
| 按住按键 | 跨后续节点保持按下 |
| 释放按住输入 | 释放租约拥有的按键和鼠标按钮 |

长按流程应始终设计释放路径。即使运行时会在 Run 异常结束时回收输入租约，显式释放仍能让正常路径更清楚。

## 应用

| 常用节点 | 用途 |
| --- | --- |
| 启动应用 | 使用“桌面应用”槽位启动程序 |
| 终止应用 | 终止该槽位对应的程序 |

应用槽位包含可执行文件和参数。工作流只引用槽位，不携带另一台电脑上的绝对路径。

## 输入录制

| 常用节点 | 用途 |
| --- | --- |
| 回放键鼠宏 | 执行可编辑的离散键鼠动作 |
| 回放精准轨迹 | 按原始时序回放连续轨迹和相对鼠标输入 |

使用前先阅读[资源与录制](../resources/index.md)。宏与精准录制的选择和组合示例见[节点使用场景](scenarios.md)。
