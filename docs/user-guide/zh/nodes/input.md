# 输入节点

## 点击指针与移动指针

指针节点在配置的自动化目标内工作。位置可以是固定值、当前鼠标位置或上游计算结果。

- 比例坐标适合不同分辨率下的相同布局。
- 客户区像素适合尺寸固定的窗口。
- 屏幕绝对位置容易受窗口移动影响，只在明确需要时使用。

需要点击后把鼠标移回原处时，先读取当前位置，执行移动/点击，再使用保存的位置恢复。

## 按键与组合键

按键节点适合单次按下、释放或组合键。需要跨多个节点保持按住状态时，应使用带 Run 级输入租约的节点，并在
正常路径和错误路径都释放；Run 异常结束时运行时也会尝试回收租约。

## 播放宏与精准录制

宏适合可编辑的离散动作；精准录制适合连续轨迹和相对鼠标移动。播放前应确认目标分辨率、窗口客户区和鼠标
校准与录制资源相符。两类资源的详细区别见[资源与录制](../resources/index.md)。
