# 数据处理节点

数据节点通常不会操作外部目标。它们接收上游值，完成判断或转换，再把结果交给分支、自动化或网络节点。

## 逻辑与比较

| 常用节点 | 用途 |
| --- | --- |
| 与 / 或 / 非 | 组合多个布尔条件 |
| 选择 | 根据条件从两个同类型值中选择一个 |
| 相等 / 不相等 | 比较两个兼容值 |
| 大于 / 小于 / 大于等于 / 小于等于 | 比较数字范围 |

比较节点只产生布尔结果；把结果连接到“分支”后才会改变执行路径。

## 数学

| 常用节点 | 用途 |
| --- | --- |
| 加、减、乘、除 | 基础数值计算 |
| 绝对值 | 消除方向，只保留差值大小 |
| 最小值 / 最大值 | 从两个数字中选择边界 |
| 限制范围 | 把数字约束在最小值和最大值之间 |
| 四舍五入 / 向上取整 / 向下取整 / 截断 | 把小数转换为需要的整数语义 |
| 取模 | 周期计数和奇偶判断 |

整数和普通数字是不同类型。需要连接整数端口时，使用明确的取整转换，不要依赖隐式截断。

## 文本

| 常用节点 | 用途 |
| --- | --- |
| 连接文本 | 把多段内容组合成字符串 |
| 包含 / 开头是 / 结尾是 | 判断简单文本条件 |
| 查找位置 / 截取 | 从已知格式中提取片段 |
| 替换 | 修改匹配文本 |
| 正则匹配 / 正则提取 | 处理结构变化但模式稳定的文本 |
| 去除空白 / 大小写转换 | 规范化输入后再比较 |

简单条件优先使用包含、开头或结尾节点；只有需要模式表达能力时再使用正则，避免难以维护的表达式。

## 集合与 JSON

| 常用节点 | 用途 |
| --- | --- |
| 追加、获取、切片、长度、包含 | 操作列表 |
| 拆分文本 / 连接列表 | 在字符串和文本列表之间转换 |
| 解析 JSON | 把 JSON 文本变成结构化值 |
| JSON 路径 | 从结构化 JSON 中读取指定位置 |
| JSON 字符串化 | 把结构化值转换为文本 |

遍历列表时，把列表连接到“遍历”节点；不要为固定数量的元素复制多套相同节点。

## 坐标与结构拆分

| 常用节点 | 用途 |
| --- | --- |
| 创建点 | 从 X、Y 和单位组成位置 |
| 偏移点 | 在已有位置基础上增加偏移 |
| 点距离 | 计算两个位置之间的距离 |
| 点周围区域 | 根据中心点生成矩形区域 |
| 拆分点 / 拆分区域 | 读取结构中的独立字段 |

连接自动化节点前确认坐标单位一致。比例、客户区像素和屏幕像素不能只靠数值大小判断。
