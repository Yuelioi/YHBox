# 更新与备份

## 更新前

1. 停止所有活动 Run 和输入录制。
2. 等待设置保存状态完成。
3. 导出重要工作流。
4. 关闭 Yotta，等待关闭阶段 Modal 消失。
5. 备份本机 Yotta 数据目录。

Windows 默认数据目录为：

```text
%LOCALAPPDATA%\Yotta\Yotta
```

不要在 Yotta 运行时只复制某个数据库文件。运行中的数据库可能还有 WAL 数据；需要完整本机备份时，先正常
退出，再复制整个数据目录。

## 安装新版本

解压新版本到固定目录，再启动新的 `Yotta.exe`。不要把多个版本的文件混合覆盖在同一目录；保留旧程序包，
直到确认新版本能打开设置、工作流和资源。

程序文件和用户数据分开保存。移动或替换程序目录通常不会删除本机工作流，但开机自启路径可能需要在新版本
启动后重新同步。

## Alpha 版本

当前 `4.0.0-alpha.N` 使用标准预发布版本号。`N` 增加表示同一 4.0.0 Alpha 线上的后续测试版本。Windows 文件
属性使用第四段表示 Alpha 次序，例如 `4.0.0-alpha.2` 对应 `4.0.0.2`。

Alpha 阶段可能调整界面、节点契约或数据格式。Yotta 会执行受支持的迁移并拒绝无法安全读取的未来格式，但
这不能替代你自己的工作流导出和数据目录备份。

## 恢复

- 单个工作流：从之前导出的工作流包重新导入。
- 设置损坏：Yotta 会优先从有效的主文件、备份或 staging generation 恢复。
- 工作流无法打开：可能进入恢复/隔离列表，由你修复或删除，不会静默用默认内容覆盖。
- 完整回退：退出 Yotta 后恢复整个数据目录，并使用与该备份兼容的程序版本。

## 不要手工删除的内容

不要直接清理数据目录中的对象、数据库、运行锁或迁移文件。资源字节可能由多个工作流共享，手工删除会造成
引用损坏。需要释放空间时使用 Yotta 提供的删除入口，并保留最近备份。
