# 快捷键

Yotta 只在快捷键已经配置或由功能注册时展示对应条目。输入框为空表示没有绑定，不需要额外的“未绑定”状态。

## 快捷键类型

| 类型 | 生效范围 | 示例用途 |
| --- | --- | --- |
| 系统 | Yotta 运行期间全局生效 | 强停、校准、窗口捕获 |
| 录制 | 录制流程需要时生效 | 开始、暂停、停止、取消 |
| 工作流 | Yotta 运行期间全局生效 | 启动或停止指定工作流 |
| 计划 | 计划启用且注册成功时生效 | 手动触发计划 |
| 编辑器 | 仅工作流编辑器内生效 | 保存、撤销、画布操作 |
| 启动器槽位 | 仅启动器显示且开关开启时生效 | 修饰键加 `1–9` |

## 设置组合键

1. 打开“设置 → 快捷键”。
2. 点击需要修改的输入框。
3. 按下完整组合键。
4. 完成捕获后自动保存。

捕获期间，Yotta 会临时暂停已有全局热键，防止旧绑定抢先触发。结束后会恢复注册。

## 冲突与保留组合

- 同一个组合不能同时分配给两个全局条目。
- 系统或编辑器保留的组合会被拒绝。
- 其他程序已经占用的 OS 全局热键可能注册失败。
- 游戏或安全软件可能拦截某些组合，即使系统注册成功也应实际测试。

错误提示会指出冲突条目。更换组合后重试；不要通过同时快速提交多个输入框绕过检查。

## 工作流快捷键

可以从工作流列表、工作流编辑页面或快捷键管理页设置。触发时：

- 没有活动 Run：启动该工作流；
- 已有活动 Run：停止该工作流的活动 Run。

工作流快捷键属于本机配置，不随导出的工作流包分享。

## 启动器 `1–9`

启动器快捷键与“打开启动器”的方式无关。开启后，只有在启动器显示期间，前九个有效工作流才会注册共享
修饰键加 `1–9`；隐藏启动器后立即释放。

详见[悬浮启动器](../launcher/index.md)。

## 重置默认

“重置默认”只恢复内置系统和录制快捷键。工作流、计划和启动器内容不会被重置。执行前确认自定义组合是否
需要记录。
