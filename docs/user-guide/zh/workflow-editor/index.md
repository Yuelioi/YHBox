# 工作流编辑器

![工作流编辑器](../../assets/workflow-editor.png)

编辑器由子图管理、画布、检查器、顶部操作区和底部运行工具组成。

第一次进入时建议先阅读[工作流编辑器完整导览](interface-tour.md)。如果还没有完成桌面自动化配置，请从
[第一次桌面点击](../getting-started/index.md)开始。

## 画布

- 从“添加节点”选择节点，或使用快速添加菜单。
- 拖动节点调整位置；框选后可以批量移动、复制或删除。
- 从输出端口拖到兼容的输入端口建立连接。
- 使用注释记录流程意图、限制和维护说明。
- 使用横向或纵向自动布局整理复杂流程。

## 信号线与数据线

信号线决定“什么时候执行”。数据线传递文本、数字、布尔值、位置、区域、图像和其他数据。一个节点可以在
收到信号时读取多个数据输入，然后把结果传给后续节点。

连接不兼容的端口时，编辑器会拒绝连线或提供转换建议。不要为了让线连上而随意改变数据类型；先确认下游
节点真正需要的值。

## 检查器

选中节点后，右侧检查器用于修改标签、配置字段和输入绑定。配置槽位通常指向设置中的网络、应用、自动化或
AI 目标。删除或更换目标后，引用它的节点会在检查时报告问题。

## 保存与检查

保存前，Yotta 会检查当前内存草稿。发现旧节点、不合法字段或错误连线时，编辑器会保留你的修改并定位到
相关节点；修正后再次保存即可。

“检查”只验证当前草稿，不会运行目标程序。建议在大规模修改、导入工作流或升级节点后先检查再运行。

## 运行、停止和调试

- “运行”从主图入口开始执行。
- 工作流运行时，再次触发同一启动入口可以停止对应 Run。
- “时间线”显示节点尝试、动作结果、错误码和状态证据。
- “调试”支持断点、继续、暂停和单步。

Run 会固定使用启动时的工作流版本；运行过程中继续编辑不会改变已经开始的 Run。

## 子图

子图用于封装可复用流程。主图通过子图调用传入数据并接收输出。删除子图前应检查所有调用位置；折叠为子图
或展开调用时，编辑器会维护内部节点和连线，但仍应重新执行一次“检查”。
