# 认识主界面

## 工作流

创建、整理、导入、导出和运行自动化流程。工作流是 Yotta 的主要执行单元。

## 资源库

保存可以在多个工作流中复用的内容：

- 键鼠宏：可逐条编辑的按键、点击、滚轮和等待动作。
- 精准录制：保留鼠标连续移动、拖拽、相对视角和原始时序。

## 计划

通过手动、定时、间隔或快捷键触发一个或多个工作流。计划适合无人值守或固定时间执行的任务。

## 设置

![设置页面](../../assets/settings.png)

设置按主题组织，包括通用行为、快捷键、输入校准、悬浮启动器、AI、MCP、网络目标、桌面应用和自动化目标。
修改会自动保存到本机；带“重启生效”标记的项目需要重新启动 Yotta。

## 底部运行工具

编辑器底部提供诊断、日志、时间线和调试入口。工作流没有按预期执行时，优先查看时间线中的失败节点和稳定
错误码，而不是只观察目标程序的画面。
