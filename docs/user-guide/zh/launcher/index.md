# 悬浮启动器

悬浮启动器适合在目标程序前台时执行高频工作流，不必反复切回 Yotta 主窗口。

## 配置内容

在“设置 → 悬浮启动器”添加工作流、文字标题和分隔符。所有项目都可以拖拽排序；工作流条目可以设置显示名
和图标。

显示方式包括图标与文字、仅图标和纯文字。内容尺寸提供极小、小、中、大和超大五档；中为默认档，超大保持
最大显示尺寸。

## 1–9 槽位快捷键

开启“启动器快捷键”后，启动器显示期间前九个有效工作流会注册共享修饰键加数字 `1–9`。隐藏启动器后这些
快捷键立即释放，不会继续拦截其他程序输入。

修饰键可以组合 Ctrl、Shift 和 Alt，但至少保留一个。关闭启动器快捷键开关不会删除启动器条目。

## 运行与停止

点击条目或按对应槽位快捷键会启动工作流。条目处于运行状态时，再次触发同一条目会停止对应 Run。启动器
底部会显示停止提示和当前快捷键。

关闭启动器只是隐藏窗口，不会自动停止已经开始的工作流。
