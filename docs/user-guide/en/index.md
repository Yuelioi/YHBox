# Yotta User Guide

[中文](../zh/index.md)

Yotta is a local-first visual automation app. Connect typed nodes for windows, input, data,
Android, browsers, HTTP services, scripts, and AI, then run the workflow manually, from a hotkey,
from a schedule, or from the floating launcher.

> This guide targets `4.0.0-alpha.2`. Export important workflows before upgrading an alpha build.
