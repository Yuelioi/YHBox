# Floating Launcher

Add workflows, headings, and separators under Settings → Floating Launcher, then drag to reorder.
Choose icon-and-text, icon-only, or text-only layout and one of five content sizes.

When launcher shortcuts are enabled, the first nine valid workflows register modifier + `1–9` only
while the launcher is visible. Hiding it releases those keys immediately.

Clicking or pressing a slot starts its workflow. Triggering the same item while it is active stops the
corresponding Run. Hiding the launcher does not stop Runs already started.
