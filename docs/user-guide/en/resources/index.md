# Input Recordings

Workflow references remain stable when you rename or recategorize a library resource.

## Keyboard/mouse macros

![Macro editor](../../assets/macro-editor.png)

Macros convert recording into editable key, click, scroll, move, and wait actions. Use them for menu
navigation, fixed-position clicks, and short input sequences. Review accidental input and excessive
waits before saving.

## Precise recordings

![Precise recording editor](../../assets/precise-recording.png)

Precise recordings preserve original timing, continuous movement, dragging, and relative motion.
Trim start/end boundaries before saving. Yotta repairs press/release state when a trim boundary falls
inside a held interval.

Relative playback requires a valid counts-per-360 calibration. Use separate profiles for different
games or in-game sensitivities.

| Need | Resource |
| --- | --- |
| Edit individual keys and clicks | Macro |
| Preserve drag, continuous path, or camera turn | Precise recording |
