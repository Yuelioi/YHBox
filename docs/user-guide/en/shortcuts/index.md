# Shortcuts

An empty input means no binding; no extra “Unbound” label is necessary.

System shortcuts work while Yotta runs. Recording shortcuts control capture. Workflow shortcuts start
an idle workflow or stop its active Runs. Schedule shortcuts trigger schedules. Editor shortcuts are
local to the editor. Launcher `1–9` shortcuts exist only while the launcher is visible and enabled.

Click a shortcut input and press the complete chord. Existing global shortcuts pause during capture
and resume afterward. Yotta rejects duplicate or reserved chords and reports OS registration failure.

Workflow shortcuts are local settings and do not travel with exported workflows. Reset Defaults
restores built-in system and recording bindings only.
